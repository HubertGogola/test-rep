# Dynamic Player DNA — Advanced Streamlit Demo

Advanced public portfolio application inspired by a bachelor thesis on dynamic football player profiling.

## Included
- Executive dashboard
- Player DNA lab
- Player similarity engine
- Cohort explorer
- PCA explorer and loading matrix
- K-means / GMM model lab
- Dynamic trajectory analysis
- HMM transition matrix + Sankey flow
- Kaplan–Meier analysis
- Methodology / interpretation page

## Privacy
All player-level data in the public demo are fully synthetic. They do not represent real players, real matches, or anonymised copies of the original dataset.

## Deploy
Replace your current `app.py`, `requirements.txt`, `data/` folder and `.streamlit/` folder with these files. Commit to GitHub. Streamlit Community Cloud will redeploy automatically.
